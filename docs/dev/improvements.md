2. **Where each value came from + Verify** (per field: page, method, date; re-check button and automatic re-checks).
3. **Company page and products** (short profile, product records, MFI category list).
4. **Saved Pages & Scans** (inside NetGate, own worker container): saves pages and whole sites, recipes, page library; the Chrome extension talks to NetGate.
5. **Authentik** (one login, 2FA) and **HTTPS**.
6. **Faster lists**: counts and completeness in SQL; Postgres full-text search.
7. **Bigger AI** on a GPU PC; later fine-tuning from the exported decisions.
8. **Automatic tests on GitHub** (CI) for every change.
9. **Health warnings** on the Dashboard (disk space, queue stuck, renderer restarts).
10. **Etsy / Amazon** methods; **watch lists** (tell me when a contact changes).
