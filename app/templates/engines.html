Search Engines

Web searches go through NetGate's own search box (SearXNG), which asks the engines switched on here. Some engines block automated searches now and then (a CAPTCHA); the list shows which ones work, which block and since when, so you can switch a blocking one off. Free engines only for now — paid backup keys come later.
