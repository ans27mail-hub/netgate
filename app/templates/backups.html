Where They Are and How to Restore

Backups are saved in the folder set as BACKUP_DIR in the .env file of NetGate on the server (normally ~/apps/netgate/backups). Put it on another disk or a shared folder — for example BACKUP_DIR=/mnt/d/netgate-backups — so a broken disk doesn't take the backups with it, then run netgate update.

To put a backup back, on the server run netgate restore to list them, then netgate restore <file name>. It asks before replacing anything and first saves a safety copy of the data as it is now. Restoring is only possible on the server, never from this page.
