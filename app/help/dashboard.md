The Dashboard is the first page you see. Click **NetGate** (top left) or **Dashboard** to come back to it.

- **At a glance** — companies waiting in the Inbox (new and enriched), contacts (and how many were added this week), accept / reject decisions this week, searches running / waiting / failed, and what last night's run found. Click a box to open that page.
- **Needs attention** — things worth doing now, each with a button: failed requests, eBay keys missing, a directory where many contacts miss the same field (**Enrich them**), keywords that were never run (**Run now**), and enriched companies ready to decide (**Review**).
- **Quick actions** — review the Inbox, run discovery, add a contact.
- **System** — whether the AI server, the hidden browser, the search engine and the eBay connection are reachable. Red means NetGate can't reach it right now; see [Troubleshooting](/help/troubleshooting).
- **Directories** — every directory with contacts, % complete, Inbox waiting, search methods and last search.
- **Recent activity** — accepts, rejects, moves, finished searches and night runs.

People with access to only some directories see only those on the Dashboard.
