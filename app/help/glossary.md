| Word | Meaning |
|---|---|
| **Contact** | One company or store. It exists once, even when it is in several directories. |
| **Directory** | A list of contacts of one kind, e.g. Manufacturers or Online retailers. Each has its own fields, search methods, keywords and AI instructions. |
| **Inbox** | Where new contacts wait until someone accepts or rejects them. |
| **Accept** | Put a contact from the Inbox into a directory. |
| **Reject** | Say a contact doesn't belong. It moves to the *Rejected* tab, isn't suggested again for that directory, and can be restored. |
| **Discover** | A search for new companies. Results go to the Inbox. |
| **Keyword** | A saved search of a directory, e.g. “leather motorcycle jacket”. |
| **Search method** | How a directory searches: Web search, Directory site, eBay search… |
| **Enrich** | Look for a contact's missing details. |
| **Field** | One piece of information, e.g. City, Email, Seller rating. |
| **Filled from** | Who fills a field: the AI and code from web pages, a method like eBay, or only people. |
| **Request** | One search or enrich job. See the Requests page. |
| **Reject List** | Keywords that are never searched again (until restored). |
| **Night run** | Searches and enriching done automatically at night. |
| **AI suggests** | NetGate's guess, based on your earlier accept / reject decisions. |
| **Role** | A named set of permissions, e.g. Researcher. |
| **Saved view** | A set of filters on All contacts or a directory, saved with a name. |
