NetGate builds **business directories** for you: manufacturers, suppliers, online shops, eBay sellers and so on. It searches the web, reads the pages it finds, picks out each company's details, and keeps everything up to date.

## How it works

1. **Search.** A *keyword* (for example “leather glove manufacturers”) is searched with the directory's **search methods**: web search, directory sites, or eBay.
2. **Read.** NetGate opens the pages it finds, including the next pages of lists and each company's profile. Pages that need JavaScript are opened in a real (hidden) browser.
3. **Pick out details.** Plain code finds emails, phones, WhatsApp, social links and addresses first. The AI on your own server reads the text for everything else (names, products, number of employees…).
4. **Inbox.** New companies go to the **Inbox**. Nothing reaches a directory until a person accepts it.
5. **You decide.** Accept a company into one or more directories, or reject it with a reason. NetGate learns from these decisions and suggests what to do next time.
6. **Enrich.** Missing details are filled later by *Enrich*: it reads the company's own website, searches for it, and checks marketplaces like eBay.

## Where things are

| On the left | What it is |
|---|---|
| **Dashboard** | The start page: numbers, what needs attention, system status |
| **Inbox** | New companies waiting for a decision |
| **All Contacts** | Every accepted company, with filters and saved views |
| **Directories** | All directories as cards; each opens its own page |
| **Requests** | Every search and enrich: pause, stop, delete, reject |
| **People** | Users, roles and login history (for admins) |
| **Settings** | Directories, AI, night jobs, crawler, your display and password |
| **Help** | These pages, and *Ask NetGate* |

The **?** button at the top of each page opens the help for that page.
