The **Keyword Library** (menu → **Keywords**) is one shared list of search words, sorted into **categories** — for example *Products* (leather gloves, motorcycle jackets), *Buyer types* (distributor, wholesaler), *Countries and cities* (Germany, Italy) and *Extra words* (manufacturer, OEM). Everyone who may run searches can pick words from it; people with the permission **Manage the keyword library** can change it.

## The library
- **Add words** — type one or many (one per line) into a category. The same word is never added twice.
- **Open a word** to rename it, move it, add a note, switch it off, or see how often it was used and how many accepted companies it found.
- **Tick several words** to move, merge, switch on/off, translate or delete them together.
- **Export CSV / Import CSV** to edit the list in a spreadsheet.

## Languages and translations
In **Directory Settings → Basics** tick the languages a directory searches in (for example English and German). When a search needs a word in German and the word has no German translation yet, NetGate's **local AI translates it once** and saves it. You can see and change every translation when you open the word, and tick **Checked** when a person has looked at it. **Translate Now** fills missing translations straight away.

## Search Builder
**Keywords → Search Builder** (or **Build from the Keyword Library →** in the Run Discovery window):
1. Choose the directory.
2. Tick words in each category — for example two products and three countries.
3. Tick the languages.
4. The preview shows every combination (one word from each category) in each language, at most 100. Warnings show combinations on the reject list, already a keyword, or searched in the last 14 days.
5. **Run Now** starts one request per combination; **Add to Directory Keywords** saves them for the night run; or do both.

From **Requests → Edit and Run Again** you can also **Pick From the Keyword Library**.
