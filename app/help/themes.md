Settings → **Themes** (needs *Display & themes for everyone*):
- **Theme for everyone** — the one people see by default. **Let each person pick their own** — then everyone can choose under Settings → Display → My theme. **Use Dark when the computer is in dark mode** — follows the computer's setting.
- **Use** makes a theme the one for everyone; **Try for Me** changes it only for you.
- **Copy** a theme to make your own, then **Edit**: 8 colours (menu, menu text, page, cards, lines, text, grey text, accent), font, corners and spacing. The preview changes as you pick colours. NetGate warns when text would be hard to read.
- Built-in themes (**NetGate Classic**, **Dark**) can't be changed; copy them instead.

A theme changes only colours and sizes — the layout stays the same.
