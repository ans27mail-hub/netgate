Use the Test Directory.

1. Click + Run Discovery, pick the Test Directory, type “leather gloves Sialkot” and start. => A request appears on Requests and starts running.
2. Wait until it finishes. => New companies wait in the Inbox for the Test Directory, not in the directory itself.
3. Open the request's Debug view (Developer Tools). => You see the searches, the pages read and what the AI answered.
4. (v1.0) In the Run Discovery dialog click “Build from the Keyword Library →”. => The Search Builder opens for that directory.
