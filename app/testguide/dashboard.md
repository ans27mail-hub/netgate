Check the start page.

1. (v1.0) Open the Dashboard on a wide screen. => The number tiles fill the whole width evenly, with no empty space on the right.
2. (v1.0) Look at Needs Attention and Running Jobs. => Both boxes are the same width, side by side (one under the other on a phone).
3. Look at Quick Actions. => The buttons are there and open the right pages.
4. Click a directory row in the directories table. => That directory opens.
5. Wait 10 seconds with a request running. => Running Jobs updates by itself.
