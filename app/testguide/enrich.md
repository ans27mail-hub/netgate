---
title: Enrich (filling missing details)
feature: enrich
order: 34
---
1. Open a contact with missing fields and click Enrich Now. => A request starts; when done, the card shows the fields it found and from which page.
2. Use the ▾ next to Enrich Now, tick only one step and run. => Only that step runs (see Debug).
3. Run “Check all again”. => Pages read before are opened again.
