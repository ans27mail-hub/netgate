---
title: Moving contacts between directories
feature: move-contacts
order: 46
---
Use two directories with different fields.

1. (v1.0) On a big card choose another directory in Move Here. => A preview shows which details stay but are hidden, and which fields are missing there.
2. (v1.0) Tick “Enrich the missing fields now” and move. => The contact is in the new directory and an Enrich request starts.
3. (v1.0) On the big card look at Other Details. => Details the directory has no field for are listed, with Add This Field to this directory.
4. (v1.0) Click Add This Field. => The field is added to the directory and the detail now shows in the normal field list.
5. (v1.0) In Directory Settings → Fields, set a field “Same as” another directory's field. => Both directories now show the same value for it.
6. Tick several contacts in the list and move them. => All of them move; the preview counts them.
