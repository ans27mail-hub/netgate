Menu → Keywords.

1. (v1.0) Open Keywords. => The library shows categories (Products, Buyer types, Countries and cities, Extra words) with example words.
2. (v1.0) Add three words to Products in one go (one per line). => All three appear; duplicates are not added twice.
3. (v1.0) Open a word, add a German translation by hand, tick Checked and save. => The word shows DE as checked.
4. (v1.0) Tick two words and choose Translate (German). => The local AI fills the missing translations, marked as AI.
5. (v1.0) Open Search Builder for the Test Directory, tick one product and one country, and English + German. => The preview shows every combination with its language, and warnings for searches done lately.
6. (v1.0) Click Run Now. => Requests start, one per combination; German ones search with the German words.
7. (v1.0) Click Add to Directory Keywords instead. => The combinations are saved as directory keywords with their language.
8. (v1.0) Export the library as CSV, then import it again. => Nothing is duplicated.
