title: Directories and the directory page
feature: directories
order: 12
---
1. (v1.0) Open Directories and click anywhere on a directory card (not only its name). => The directory opens.
2. (v1.0) Switch to the list view and click anywhere on a row. => The directory opens.
3. Click a button or link inside a card. => Only that button acts; the directory does not open as well.
4. Open a directory and search with the top search box. => Only that directory's contacts are searched.
