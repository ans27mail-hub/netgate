---
title: Browser Search and Solve CAPTCHA Yourself
feature: browser-search
order: 28
---
Directory Settings → Search Methods → Browser Search; Settings → Search Engines → Browser Search.

1. (v1.0) Turn on Browser Search for the Test Directory and run Discovery. => The request opens search pages in NetGate's browser and finds companies.
2. (v1.0) When a search engine shows a CAPTCHA, wait on any page. => A pop-up “Solve the CAPTCHA” opens for the person who started the request, and Needs Attention shows it on the Dashboard.
3. (v1.0) Click on the picture in the pop-up as you would on the real page. => Your clicks reach the page; when solved the pop-up says so and closes, and the search goes on.
4. (v1.0) Click Give Up instead. => The engine is paused for a few hours (Settings → Search Engines shows it) and the search uses another engine or stops.
5. (v1.0) In Settings → Search Engines → Browser Search click Use Again Now next to a paused engine. => It is not paused any more.
6. (v1.0) Change the pause between searches and the searches per hour, then save. => The values stay after reloading.
