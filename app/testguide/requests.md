title: Requests (pause, stop, delete, reject)
feature: requests
order: 60
---
1. Pause a running request, then Resume it. => It continues where it stopped.
2. Stop a request. => It ends as Stopped; what it found is kept.
3. Use Edit and Run Again with other words. => A new try starts; earlier pages are skipped.
4. (v1.0) On Edit and Run Again use Pick From the Keyword Library. => Words from the library fill the search; the try shows its language.
