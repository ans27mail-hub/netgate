1. Settings → Night Jobs: set a window that starts in 2 minutes and save. => The night run starts at that time (see Requests).
2. Wait for the window to end. => The night run stops by itself.
3. (v1.0) With “Verify contacts not checked for” set, look at the night run's numbers. => It shows how many contacts were verified.
