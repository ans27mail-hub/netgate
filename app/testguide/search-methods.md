Directory Settings → Search Methods.

1. Open a directory's settings and turn a method off, then Save. => The method stays off after reloading the page.
2. (v1.0) Turn on Browser Search and look at its options. => You can set results wanted, pages per search, minutes per search and engines.
3. Run Discovery with only one method ticked. => The Debug view shows only that method was used.
